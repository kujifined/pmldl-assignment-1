# Raw data

`penguins.csv` is the curated Palmer Penguins dataset from the
[`palmerpenguins` repository](https://github.com/allisonhorst/palmerpenguins/blob/main/inst/extdata/penguins.csv).

The dataset is derived from observations collected by Dr. Kristen Gorman and the
Palmer Station, Antarctica LTER. See the upstream repository for the complete
license and citation information.
